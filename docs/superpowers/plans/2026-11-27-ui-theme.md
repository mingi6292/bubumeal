# UI 디자인 적용 ("따뜻한 식탁") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 앱 전체에 "따뜻한 식탁" 색·SUIT 글꼴·둥근 모서리를 입히고, 주간 식단표를 하루 카드 7개 세로 목록(오늘 강조, 오늘 카드로 자동 스크롤)으로 바꾼다.

**Architecture:** `ui/theme/`에 `BubuMealTheme`(MaterialTheme을 감쌈)을 두고 `App()`이 쓴다. 각 화면은 `MaterialTheme.*`만 보므로 테마 하나로 모든 화면이 바뀐다. 주간 화면은 `WeeklyScreen` 내부만 다시 그리고(매개변수 불변), 스크롤 판단은 순수 함수로 빼서 테스트한다.

**Tech Stack:** Kotlin 2.4, Compose Multiplatform 1.12.2(Material3, `org.jetbrains.compose.resources`), kotlinx-datetime, kotlin.test

**Spec:** `docs/superpowers/specs/2026-11-27-ui-theme-design.md`

## Global Constraints

- 밝은 테마만. 다크 테마 분기를 만들지 않는다.
- 확정 색: 배경 `#faf4ea`, 카드 `#fffdf8`, 글자 `#3d2f25`, 보조 글자 `#8a7565`, 선 `#eadfce`, 강조 `#c4552d`. 나머지는 spec 3장 표의 값 그대로.
- 글꼴: SUIT v2.0.5 OTF 4굵기(400/500/600/700)만. 다른 굵기 파일은 넣지 않는다.
- 배치 변경은 `ui/weekly/WeeklyScreen.kt`만. 다른 화면은 색·글꼴·모서리만 바뀐다(코드 배치 변경 금지).
- `WeeklyScreen`의 매개변수, `WeeklyViewModel`, `AppNavHost`는 바꾸지 않는다.
- 강조색 글자는 14sp 이상이거나 SemiBold 이상으로 쓴다.
- 기존 기능(주 이동, 이번 주로, 빈 주 안내, 로딩 막대, 끼니 편집, 접근 상실 안내, `hasNoPlan` 문구) 유지.
- 명령은 PowerShell(`.\gradlew.bat`). iOS 빌드는 하지 않는다. 에뮬레이터는 사용자가 켜 둔 것만 쓴다(직접 켜지 않음). adb는 `-s emulator-5554`로 대상 지정.
- 사용자는 KMP가 처음이다. 새 개념(Compose 리소스의 `Font()`, `LazyColumn`/`LazyListState`, `rememberSaveable`)은 작업 전에 짧게 설명한다.
- 커밋 메시지는 한국어, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **공백 없는 50자 메뉴**(예: `가`×50 또는 URL) — 카드 밖으로 넘치지 않고 줄바꿈되어 카드가 길어져야 한다. → Task 3 에뮬레이터 확인 항목.
2. **해가 바뀌는 주**(2026-12-28 ~ 2027-01-03)에 오늘이 1월 1일 — 오늘 카드 인덱스가 4여야 한다. → Task 2 테스트 `todayIndex_yearBoundary`.
3. **동반자 연결만 바뀐 같은 식단표**(`hasCompanion` false→true) — 같은 식단표이므로 스크롤하지 않아야 한다. → Task 2 테스트 `scrollKey_ignoresCompanionChange`.
4. **금요일 카드까지 내려 본 뒤 화면 회전·설정에 다녀오기** — 보던 위치 그대로. → Task 3 에뮬레이터 확인 항목.
5. **시스템 글자 크기 최대(1.3배 이상)** — 상단 제목·주 범위가 겹치거나 잘리지 않아야 한다. → Task 4 에뮬레이터 확인 항목.
